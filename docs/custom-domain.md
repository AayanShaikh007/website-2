# Portfolio domain

Primary production URL: https://aayanshaikh.dev/.

The domain is registered at Name.com and uses its DNS hosting. Vercel project `aayan14/aayanshaikh` serves production from `AayanShaikh007/website-2` main.

DNS records configured from the values Vercel displayed:

- Root A record: `216.198.79.1`, TTL 300.
- `www` CNAME: `5aa818ada2d4873b.vercel-dns-017.com`, TTL 300.

Vercel issues and renews HTTPS certificates. No separate registrar SSL purchase is required. Domain-level 308 redirects in the Vercel dashboard send `www.aayanshaikh.dev` and `aayanshaikh.vercel.app` to the primary domain, retaining paths. Keep the apex connected to Production rather than redirecting it to www.

Canonical page URLs, social image metadata, the sharing card and security.txt now use the primary domain. Private reports remain local and are not part of domain hosting.
