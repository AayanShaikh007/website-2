# Repository working preferences

- Make frequent, small commits for each completed change. Checkpoint uncommitted work before larger edits.
- Use this repository's configured owner identity; do not backdate, fabricate contributors, or rewrite published history.
- Keep generated output, dependencies, work files, credentials, and local backups out of Git.
- Preserve the minimal portfolio style and reduced-motion behavior.
- Ground personal claims in owner-provided information. Do not invent dates, achievements, project photographs, or responsibilities.
